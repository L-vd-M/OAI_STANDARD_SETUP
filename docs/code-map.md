## Section 5: Cross-Cutting Conventions

### 5.1 Build System

#### RAN (CMake + `build_oai`)
- **Entry point:** `cmake_targets/build_oai` bash script
- **CMake presets:** `CMakePresets.json` at repo root
- **Component flags:** `--gNB`, `--eNB`, `--nrUE`, `--lteUE`, `--nr-cuup`, `--build-lib`
- **Frontend flags:** `-w USRP`, `-w SIMU`, `-w AW2S`
- **Build output:** `cmake_targets/ran_build/build/`
- **Dependency install:** `build_oai -I` (runs `apt-get` + compiles UHD, etc.)

#### CN5G NFs (CMake + `common-build` submodule)
- Every NF includes `oai-cn5g-common-build` as a git submodule (in `build/`)
- The `build_helper` script installs all C++ library dependencies
- Local cmake command pattern:
  ```bash
  mkdir build && cd build
  cmake .. -DCMAKE_BUILD_TYPE=Release
  make -j$(nproc)
  ```
- Libraries: nghttp2, pistache, spdlog, yaml-cpp, nlohmann-json, cpp_jwt, fmt, odb, mysql-connector

### 5.3 Docker Patterns

#### RAN Docker patterns
- Multi-stage builds: `base` → `build` → `runtime`
